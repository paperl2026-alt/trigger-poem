# 第0话　放学后的限定蜜瓜包（教学关）

异变：**文化祭鬼屋失控**。文化祭前一天放学后，三年A班刚搭好的纸板鬼屋被邪神漏进来的气息附身，把整座学校变成了一座巨大的鬼屋：挂满文化祭装饰，到处冒紫光，画上去的眼睛真的睁开了。可爱又瞎搞，不血腥。

## 流程（`src/game/episodes.js`）
1. 漫画（等新角色定稿后重画）：放学，全班在搭鬼屋，蔡蕾抓着限定蜜瓜包的传单冲出去 → 鬼屋活了，两人青筋暴起。
2. 小关「3年A班 鬼屋」（1 个机位，3 波）：教学提示「按住左键射击 / 松开躲避」，第一次技能充满时提示「右键必杀」。
   敌人：纸板僵尸（近战，跳上掩体咬人，必须打掉）、床单鬼（俯冲）、提灯妖（远程，吐鬼火，鬼火能打掉）。
3. 小关「文化祭走廊」（2 个机位，各 2 波）：加入唐伞妖（倒挂在天花板，掉下来扑人）。
4. 漫画：黄昏的操场，文化祭的吉祥物花车转过头来，眼睛发紫。
5. Boss「暴走吉祥物花车」（操场，一条血；眼睛 ×1.5，其余 ×0.75）：
   - 吐章鱼烧 / 气球（可打掉的飞行物），吐完滚到新位置；
   - 抬起车身砸地（紫色重击圈，霸体，只能躲）；
   - 叫出床单鬼和纸板僵尸；
   - 半血二阶段：更快、吐更多、停不下来地颠。
   持续命中积累硬直，硬直会打断吐东西和召唤。
6. 漫画：面包店空托盘，蔡蕾跪地哭成瀑布 → 夕阳下两人分一根便宜冰棍，云里有只没人注意到的紫色眼睛。

结算：本话的「绘コンテ」（分镜稿）样式，按评价发刀盾，首次通关 +300，解锁第1话。
