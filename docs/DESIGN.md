# 设计（用户定下的，推翻前先问用户）

## 作品
- 名字暂定《相对希望少女们的扣击诗》。Three.js + Electron，面向 Steam/PC。
- 题材：每一集是一个恐怖题材的"异变"打断了 JK 的日常，两位灵能少女很生气，打穿异变、回到日常。无限单元剧，没有头尾。调性比《吊带袜天使》还瞎搞。
- **一个大关 = 完整致敬一部作品**（ACG / 恐怖小说 / 恐怖游戏），一集里不混别的作品。
  - 致敬前必须实际查资料，写进 `docs/episodes/<作品>.md`；
  - 桥段、氛围、名场面可以致敬，原作角色名、造型、怪物造型、台词不直接用；
  - **致敬要靠演出看得出来**（2026-10-18 用户）：原作的名场面在关卡演出、漫画、转场、机关里演出来，七八成像、似是而非，不是"有个共同元素"就算。
- 章节：第 0 话是原创序章；其余章节都是致敬作，数量没定。第 1 话叫**腐蜜之家**（致敬《スウィートホーム》），第 2 话暂名**钟楼惊宿**（致敬 SFC《クロックタワー》）。
- **对标成品**：不是占位的 MVP。除了还没做的音效音乐，画面、交互、转场都按上线标准。"看着不一样"是好事，重复感是缺陷。
- **美术不许偷懒复用**（用户说过多次，2026-10-17 再次强调）：墙、装饰、掩体、杂鱼、场景……同一种东西要有好几个"像又不完全一样"的版本轮着用，不让玩家看久了疲劳、细看觉得穿帮。Codex 出图没有额度限制（用户买了 Pro）。

## 主角
- 两人都是 **18 岁高三生**，成年人比例；允许 NIKKE 程度的晃动和身段表现（非露骨）。不擅自加安全裤之类的保守改动。设计图由用户定稿：`art/ref/cat_sheet.png`、`art/ref/pink_sheet.png`。
- **三种语言不必一一对应**（2026-10-18 用户）：游戏里的名字、说明，英文完全可以是独立的梗、似是而非的词，不用照着中文直译（日文同理）。
- 名字是假名谐音梗，中日英各有梗，不许另起：

| | 日 | 英 | 中 |
|---|---|---|---|
| 白发猫耳娘（右臂是猫爪鬼手，灵能系，不用枪） | 猫尾 果舞瑠（=猫を被る，装乖） | Neko O'Kaburu | 庄乖（=装乖） |
| 粉衣黑双马尾地雷妹（枪手） | 蘭堂 美音 | Rando Mine（=landmine；mine=我的） | 蔡蕾（=踩雷） |

- 猫爪手背上的咒印必须和设计稿右侧特写一模一样（细则见 ART）。
- **两人的真身**（2026-10-19 用户）：猫娘其实是**付丧神**（旧物件生了灵），地雷妹其实是**人造人**（炼金术那种，不是机器人、不是生化人）。目前只用在阵亡的样子上（下面「阵亡」），剧情里要不要讲由用户定。
- 另一条路用户允许过但没批：咒印随场景 / 战斗状态变化，前提是应景、有设定（东方咒符 × 西方魔法阵）。

## 场景结构
1. 标题 + 设置：一个画面。**标题**（2026-10-17 用户第十批）：「相对希望的少女扣击诗」，配日文（相対希望の少女 引鉄詩〈トリガーポエム〉）和英文（GIRLS OF RELATIVE HOPE · TRIGGER POEM）；放在左上，不挡人物立绘和胸口；做成和界面一致的红黑白剪报字（每个字一块斜贴的纸片），代码画，不用 Codex 的字。设置里的说法要让人一看就懂（2026-10-17 用户第九批："2P 关是啥意思"）：「2P 由谁来打：AI 代打 / 手柄玩家 / 键盘玩家 / 不上场（单人）」；音量分总音量、音乐、音效三项。
2. 选关 + 背包 + 换装：一个画面，像翻彩色漫画。小关多于 3 个的大关，小关列表每页 3 行逐页翻（2026-10-18 用户选了方案 A：上下箭头、滚轮、↑↓、页码点）。
   - 每章的小卡有自己的颜色（2026-10-18 用户：三张灰卡太像）：序章是异变的紫红、第 1 话蜂蜜琥珀、占位卡冷灰的雾色。
   - 切换大关（2026-10-18 用户）：只有点左右箭头才切换，点中间的小卡不切；第一个大关没有左箭头、最后一个没有右箭头（直接不显示）；中间的小卡显示现在所在的大关（点箭头切过去就一直是那一章，鼠标离开箭头不会变回去）；鼠标移到箭头上时预览那个箭头通往的大关（序号、名字，没解锁的才有锁）；占位图（Codex 画的：两人背影走向雾里的未知小镇）只给还没有自己卡的大关。
   - 小关多的大关分页，每页 3 行：上下小箭头、页码点、滚轮、↑↓ 都能翻页（2026-10-18 用户：小箭头不能只是示意）；小箭头点它周围一圈也算。
   - 悬停 / 按下 / 选中要显眼（2026-10-18 用户：只是稍微放大、局部变化不显眼）：选中的小关整条红底白字，鼠标移上去的小关黑底白字；出发、返回、设置、页签、换位、箭头这些按钮，鼠标移上去整块换成对比色（红的变黑、黑的变红）、带白边和光，按下时闪白；书包里的按钮也是红黑互换。
3. 大关：可配置的一串步骤，例如开场漫画 → 小关 → 漫画 → 小关 → 漫画 → Boss → 结尾漫画。
   - 小关之间、进第一个小关前、Boss 打完，都是漫画转场；
   - 不许把几个场景（比如楼梯）不切换就硬接。
4. 结算 → 回选关。结算做简单的记录（2026-10-17 用户第七批）：两人历战值涨了多少、升没升级，拿到多少伍德刀盾（角色满破以后改成追加伍德刀盾）；画面贴合大关主题。
- 换画面像翻漫画：分镜重新排列（标题↔选关已做）。
- 漫画**不要文字**（序章已定；其他章节没说，默认也不要）。
- **漫画转场的规矩**（2026-10-17 用户）：
  - 画面里只出现两位主角、杂鱼、Boss，**不画别的人，严禁出现男性**（出戏、不媚宅）；
  - 不追求写实，但不能有穿帮：比如手机背对玩家，玩家就不该看到屏幕内容；
  - 简单的过场**一页走完**，不拆成好几页大分镜；**不做整页的大运镜**，只在各个小格里做局部的小运镜；整页要看得清流程和细节（2026-10-17 用户：太我流、太抽象）；
  - 可以有简单的非台词文字提示（LIMITED / 限定 这种中日英都看得懂的），不是完全不能有字；**字由 Codex 直接画在漫画里**，不是程序事后贴标签（2026-10-17 用户：丑）；
  - **Codex 出整页漫画**（简单的漫画画风，贴合游戏立绘，带网点、像纸质漫画，不要 CG 渲染图），程序把格子切出来做动画；每页先出几张候选，局部不合格就局部修改（GPT 能改局部，不必整页重抽）。
  - **分镜四平八稳**（2026-10-17 用户第八批）：格子是规整的矩形方格，格子里不再切小格，不斜切，好做局部分镜动画；内容不要费解。
  - **镜头不能穿帮**（2026-10-17 用户第八批："玩家会同时看到手机的两个画面？"）：要么画角色拿着手机 / 本子，头顶气泡里是她想的限定；要么越过她的肩膀看到手机屏幕 / 本子内容（看不到她的脸）。给 GPT 的提示词要很长、把每格画面写具体。
  - 做法：Claude 设计分镜（几格、每格画什么、怎么排），Codex 每格出几张候选，Claude 挑好的拼；不照搬 GPT 出什么用什么。
  - **承上启下，不只是转场**（第十七批：「你太执着于转场二字」）：漫画要讲清楚刚发生的事和接下来为什么会这样（突然出现怪物、融化的两人分身……这些为什么），不只是展示两人在空间里移动。
  - **主角的衣服必须和设定图一致**（第十七批：小过场里地雷妹的衣服明显不符）：每页对照设定图检查，不符就带着设定图局部重画，多抽几次。
- **演出**（第十七批：「我们是 3D 游戏，完全可以」）：打着打着场景塌方、两人掉下去；稍微清场后背后出现敌人，要扭头打；敌人破左右的墙、天花板、地板跳进场子（墙不是无比可靠的）；挨够打的怪破墙而出，两人循着它打开的路接着追。
- **门和小关的衔接**（第十七批）：开的门一定通往下一个小关，而且是这个小关里本来就在的门：门先作为这一小关要抵达的地方出现在尽头，清场后顺势走过去打开；要么就用漫画讲清楚两人在来回探索不同房间。小关之间不一定非得是漫画或战斗，可以是单纯的走廊、楼梯，两人不打也走一段；手段穿插着用，单调的最大问题是一个方案无限重复。
- **地形和机关**（第十七批：「地形太死板，一个素材放好就不敢变换」）：场景会变换空间结构、换素材；舞台上的障碍物越打越烂、机关越触发越变；机关比如吊桥通路、点燃照明的火、堵住不断出怪的口子然后两人另找出路……参考原作「用 A 道具解决 B 事件」的思路，按光枪游戏能做的改编，不是 1:1 照搬。
- **场景变化不只是"往前冲"**（2026-10-17 用户，长期思路）：小关里可以转弯进新区域、上下楼梯、破窗跳楼、场景被 Boss 打坏突变。允许纸片人小剧场式的出戏和漫画式夸张（黑白熊小剧场、小圆魔女结界那种），不追求 3A 物理真实；但变化要像漫画，不是只翻页或硬切分镜格。手法库和选用见下面「场景变化手法」。

## 操作
- 鼠标（1P）：移动瞄准；按住左键 = 探身射击；松开 = 躲掩体；右键 = 主动技能。没有别的按钮。
- 手柄：摇杆瞄准，RT/A 射击，LT/LB 掩体，Y/RB 主动，START 加入 2P / 菜单。2P 默认 AI，可随时被手柄或键盘接管。

## 战斗
- 从头到尾只有瞄准、射击。小关只在镜头和目标上变化，不换玩法类型。不做相生相克、不做要求瞬间换武器的设计。
- 小关里打完一波就往前推进到下一个位置再打，中间可以有演出镜头。
- **射击和掩体的节奏**：玩家要学会适当射击、酌情躲掩体。
  - 掩体不是完全无敌；
  - 有的攻击要提前打断（靠硬直）；
  - 有的攻击必须躲掩体。
- **节奏要慢下来**（2026-10-17 用户第七批："快得玩家没有反应、信息过载"）：怪物和 Boss 的出招、移动、飞行物、刷怪间隔，整体是之前的 50～60%；同时出现的威胁少一点，玩家看得清是什么、来得及决定打还是躲。
- **关卡编排要有起伏**（2026-10-17 用户第七批补充："人不是机器的响应速度和判断……游戏的节奏就在于此起彼伏的波浪，不是你教玩家必须做什么"）：
  - 一波只考一件事：要射的、要击落的、要躲的不放在同一波；要躲的大招单独来；
  - 每个停留点有强有弱：热身 → 加一点 → 喘口气 → 高潮 → 收尾，不是一直满负荷；
  - 容错靠关卡编排本身（2026-10-17 用户："容错说的不是硬编码和倍率调整"）：怪出现的频率、位置、种类；新东西第一次出现时单独来、站在看得清它来的地方（画面中间、不太近），前后留出空当，让玩家逐步上手、有"我学会了"的快乐；之后才和别的混在一起。不用伤害、预警时间的倍率去调。
- **小关里多刷几波**（2026-10-17 用户第七批）：每个停留点多打几波，用上场景的移动、翻转；杂鱼按已有的种类让 Codex 出几种相似的新造型，反复刷，降低重复感。每个小关都要让玩家熟悉一遍基本操作。
- **怪物挨打的样子**（2026-10-17 用户第八批）：中弹不会原地僵住，照样带着惯性移动、继续演；小怪血多一点，有压迫感，也让玩家多看看它的演出；死了描边马上消失。
- **怪不能站在遮挡物后面穿模**（桌子、讲台、地板翘起的棱等）。
- **攻击分三种，只给特殊攻击提示**（2026-10-17 用户第八批）：
  - **快打**：敌人的飞行道具、冲撞型特殊怪（扑过来的）：躲没有用，只能尽快打掉；
  - **快躲**：打不掉的强力攻击（喇叭声波、灭火器泡沫、Boss 大招）：射击没用，只能躲；
  - 普通的：小怪走近了咬人，玩家贪刀露头才会被打到，躲着就挡得住；**不提示**。
  - 提示的样子（2026-10-17 用户第八批定稿，推翻了纹身花纹边框和闪现字）：**只有环，不要任何文字提醒**（"文字非常碍眼……环状提示就好了"），简洁大气直观，像特别的敌人 / 攻击载体身上一直环绕着木星的卫星带：
    - **快打**：正对玩家的红粉圆环套住它，**一直来回放大缩小**，顶上一颗带翅膀的爱心；
    - **快躲**：斜着的紫色环带**绕着敌人转**：把敌人包在里面，后半圈在敌人身后被敌人挡住，玩家只看到前半圈和环的轨迹；带翅膀的爱心和小爱心像卫星一样沿着它转；**像耀斑、黑子爆发那样时不时猛地亮一下**；
    - 爱心和翅膀用程序画（干净的线条），不用 Codex 出的字和花纹。
  - **小小的闪避提示**：要躲的大招出现时，"走廊"那块场景名牌的正上方亮起一条很小的 LED 点阵警示条（参考用户给的 POLICE LINE 警戒灯牌），（2026-10-18 用户：太小 → 高度翻倍，约为场景名牌的 1.5 倍高）中日英来回切换的梗：前方高能反应 / HIGH ENERGY AHEAD / 战斗人员也请避离 / 这不是演习……样式由 Codex 出了 12 种（art/raw/r50），游戏里自己用点阵画，每次切一种。
- **AI 队友不能太勤快**（2026-10-17 用户第八批）：出手频率约 40%，瞄准偶尔失误，默认不处理要快打的东西，出现要快躲的就完全躲好；玩家什么都不做不能通关。
- **敌人要逼上来、要耐打、要多**（2026-10-18 用户第十三批）：
  - 每种杂鱼都往主角身上动，不原地踏步；两位主角的威力调低，杂鱼不能一枪一个；
  - 杂鱼波次要多；不同杂鱼动法不一样：走过来、跳着前进、突然冲撞、飘忽不定地飞、从东西底下突然跳出、左右翻滚走 Z 字；同一种杂鱼的三个版本都用上，动法也略有区别，看着像有很多种怪；
  - 扔飞行物的时候短暂霸体（玩家才有机会去打飞行物）；飞行物可以多一点，分走玩家的火力；
  - 怪不要从遮挡物后面冒出来又不越过、也不打坏它；挡在怪前面的遮挡物（不是主角身前的掩体）敌我双方都能打坏，这是 3D 游戏。
- **要和怪鏖战**（2026-10-18 用户第十七批：「敌人不耐打……没有谁规定杂鱼必须秒杀，玩家要感受到和怪鏖战的过程」）：
  - 普通杂鱼要打一会儿才死，壮的更久；只有成群飞的小东西一枪一个，而且要多（2026-10-18 第十九批：第 1 话的怪再 ×4 血，一枪一个的成群杂鱼使劲多，场上不能被打空、玩家不能闲着：上一波剩最后一只时下一波就进场）；
  - **两人手感要明显不同**（用户：「攻击力感觉你是偷懒弄一样的」）：猫娘单发重、射得慢、盯着一只打越打越痛（单体爆发）；地雷妹单发轻、射得快、能穿透（持续压制、打群）；
  - **受伤的样子**（用户：「不要直接漆黑一片，难得的素材，半透明的适当变色和消失」）：打中的地方偏色、变半透明、边缘发光，像被打散；不会越打越黑；形状和判定不变（Boss 也一样）。
- **怪离镜头要近**（第十七批：「比准星都大不了多少，特效一出基本啥也看不见」）：出场就看得清，比准星大得多；远处出场再逼过来也只在中近距离里。
- **怪的行为要多样，不能呆、不能只会扎堆**（第十七批：「完全就是机械劳动」）：
  - 残血爆冲：脆的怪掉到一半血时突然闪开 / 冲一段，期间无敌；
  - 越打越快：有的怪挨打越多、冲向主角越快；
  - 躲瞄准：被瞄准就蛇皮走位躲开，躲几下累了、或者准备出招时才抓得住；
  - 幻影洗牌（夫人的影子之类）：同时三个影子，每个都能挨打，只有一个是真的；真的挨够了就退开，再像洗牌一样重新出三个；
  - 成群飞的：一次来很多、一枪一个，让玩家来回扫；
  - 摆设活过来：骑士雕像、娃娃、画像这类东西本来是场景摆设，突然变成怪；多做几处。

## 角色性能（每人 = 枪械性能 + 一个贴人设的主动，不做被动）
- **物理净化流（枪，地雷妹）**：
  - 射速快、弹匣大、单发低、有穿透，适合打一群；持续打同一目标不断叠硬直。

## 场景变化手法（2026-10-17，Claude 按用户要求发散后选的组合，用户可改）
手法库（能做的都记在这里，按场景选组合）：
- **镜头在 3D 里走**（PanelWorld 真 3D）：
  1. 转弯：L 形走廊，镜头甩过拐角（带速度线），新区域在拐角后；
  2. 楼梯：台阶是一块块板，镜头上下楼、在平台转身；
  3. 推门进屋：拉门板滑开，镜头穿过门进新房间；
  4. 破窗：玻璃板碎裂飞散，镜头冲出窗外，跳下去的过程交给漫画；
  5. 被 Boss 打坏：墙板、天花板像书页一样被掀飞 / 折走，露出外面和 Boss；
  6. 盗梦空间式折叠：地板弯起、翘成棱（已做）；
  7. 立体书翻页：整个场景像立体书合上、压平，翻过一页，新场景从书页里立起来。
- **纸片小剧场**（黑白熊小剧场、小圆魔女结界式）：场景突然变成平的纸片舞台，人物和怪变成插在棍子上的剪纸滑进滑出，演一个短笑料 / 异变，再弹回 3D。
- **画面本身变成漫画**（后期 shader，不是翻页）：
  8. 活体分镜：战斗中的 3D 画面被斜线切成几格，每格是同一时刻的不同镜头，几秒后再合回一整个画面；
  9. 集中线隧道：速度线收拢、一闪，进入新场景；
  10. 网点 / 墨迹 / 撕纸擦除：用漫画质感的笔触把旧画面擦掉、露出新画面；
- **画好的漫画页**：3D 讲不好的（落地、Boss 全身登场、情绪、时间跳跃）用一页一镜头的漫画。
序章的选用（教室 → 走廊 → 操场）：
- 教室：平静 → 被轰中时，墙和天花板的板被冲击波掀开一瞬间（5），再合上变成异变后的样子；
- 教室 → 走廊：一页漫画（推门、跑进走廊）；
- 走廊：站点之间转弯（1）、地板折叠（6，已做）、下一层楼梯（2）；
- 走廊 → 操场：破窗（4）+ 活体分镜（8）冲出窗外 + 一页漫画落地；
- 操场 Boss：形态之间用场景被打坏（5）或立体书翻页（7）换镜头，大的变身用一页漫画；
- 纸片小剧场：放在异变发生、Boss 登场这种"出戏"的点，一关一两次，不滥用。
