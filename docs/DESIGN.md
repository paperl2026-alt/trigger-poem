# 设计定稿（按用户决定整理，变更请直接改这里）

## 题材与剧情
- 邪神入侵只是苗头；每一集是一个恐怖题材的"异变"打断了 JK 的日常，灵能少女很生气，打穿异变、回到日常。无限单元剧，没有头尾。调性要比《吊带袜天使》还瞎搞。
- **一个大关 = 完整致敬一部作品**（ACG / 恐怖小说 / 恐怖游戏），一集里不混其他作品。
- 致敬前必须实际查资料（剧情、画风、角色、名场面），写进 `docs/episodes/<作品>.md`。
- 版权：桥段、氛围、名场面的编排可以致敬；原作角色名、角色造型、怪物造型、台词不要直接用。

## 场景结构（只有三类）
1. **标题 + 设置**：一个场景。
2. **选关 + 背包 + 换装**：一个场景。选关像翻彩色漫画。
3. **大关**：一串可配置的步骤，顺序和数量按大关需要，例如：开场漫画 → 小关 → 小关 → 漫画 → 小 Boss → 漫画 → Boss → 结尾漫画。
4. **结算** → 回选关。结算界面按大关主题做成动漫分镜、名场面风格。

## 操作
- 鼠标（1P）：移动 = 瞄准，按住左键 = 探身射击，松开 = 躲掩体，右键 = 主动技能。没有别的按钮。
- 手柄：摇杆瞄准，RT/A 射击，LT/LB 掩体，Y/RB 主动，START 加入 2P / 菜单。
- 2P 默认 AI 队友，可随时被手柄或键盘接管。

## 战斗底子
- 从头到尾只有瞄准、射击。小关只做镜头和目标上的微调，不换玩法类型。
- 不做相生相克、不做要求瞬间识别后换武器的设计。
- **Boss**：一条血；不同部位伤害倍率不同；不存在"必须先打爆某部位"。
- **暴击**：只来自 Fever 的准头加成。
- **硬直**：持续命中同一目标会累积硬直，硬直会打断它的攻击；杂鱼和 Boss 在某些动作中霸体（不吃硬直）。
- 基础手感开局就要舒服（射速不能低），Fever 只是加成。

## Fever（鼓励一直打，不鼓励躲太久）
| 指标 | 怎么涨 | 加成 |
|---|---|---|
| 伤害 | 造成伤害 | 伤害 |
| 准头 | 命中（打空只略降） | 暴击率、暴击倍率 |
| 连击 | 连续击杀不断 | 装填速度 |
- 每项有等级，等级越高加成越高；躲掩体太久、长时间不开枪会衰减；被打中掉一截。

## 角色（每个角色 = 枪械性能 + 一个贴人设的主动；不做被动）
### 物理净化流（枪）
- 射速快、弹匣大、单发伤害低、有穿透，适合打一群；持续打同一个敌人会不断叠硬直。
- 主动：无限弹匣的加特林扫射，伤害和射速都上来，更容易打出硬直；主动期间命中敌人会缓慢回血。
- 主动充能：靠**命中**（不是击杀）。
### 灵能攻击流（致敬地狱老师的鬼手）
- 鬼手放出六字真言（唵嘛呢叭咪吽）当子弹：单发伤害高，大部分杂鱼几发就死；持续打同一目标伤害逐步提高；射速一般；能打出较长硬直。
- 主动：掌心放出冲击波 / 真言镭射（贯穿），准星移动变慢，高伤；期间松开左键躲掩体会中断，并按剩余主动时间回血。
- 主动充能：时间 + 击杀，充得慢。

## 局外（不做抽卡、不做 CG 奖励、不做素材链、不做消耗品）
- 唯一货币：**刀盾**，按评价发放。用途：解锁背包道具（永久、无限次使用）、扩充背包格子。
- 背包：道具各有 cost，背包容量决定每次能带哪些；出发前搭配。
- 新大关、新角色：通关解锁。
- 角色熟练度：用这个角色打就涨，每升一级加一点枪械数值；满级解锁满破形态（整套独立素材）。
- 换装：每套服装是一整套独立生成的姿势素材，不做局部贴图替换。

## 美术与 UI
- 主要视觉是 NIKKE 式的角色背影 / 侧身。
- 两名主角都明确设定为 **18 岁的高三生**，外形按成年人比例；允许 NIKKE 程度的轻度晃动和身段表现（非露骨）。晃动在引擎里程序化实现（纸片局部柔体形变）。
- 主角外形要有卖相（NIKKE 级的精致立绘感）；不要擅自加安全裤之类的保守改动。主角设计图由用户定稿。
- 不复用 MVP 美术。
- UI 要动漫式的夸张、可爱、有演出，不要"高级感"网页风：选关像翻彩色漫画，结算像动漫分镜 / 名场面，并贴合大关主题。全部美术用 Codex 出图。

## 第一关（序章 / 教学关）
- 放学的平静傍晚。两个互不认识的女孩各自赶路：
  - 一个去抢限量美食；
  - 一个去抢限量周边（别人家 IP 的，不是她自己的）；
  - 两人去的是不同的店。
- 邪神突然入侵（没有触手，没有宝石），校园异变。一个掏出枪，一个变出鬼手，两人共患难才相识，一起除魔、杀出重围、净化危机。
- **剧情（用户 2026-10-17 复述，很简单）**：
  1. 两人各自看手机 / 笔记，想起来今天得抢限定的周边 / 美食，急着放学；
  2. 这时学校被不明能量轰中；
  3. 周围的同学、老师等异化；
  4. 两人一路净化、战斗过去，在操场打完 Boss。
  - **漫画不需要文字。**
- **路线：教室 → 走廊 → 操场（Boss 战）。和学园祭 / 文化祭没有任何关系。**
- **流程**：开场漫画 → 教室 → 漫画 → 走廊 → 漫画 → 操场 Boss → 结尾漫画。
  - 进第一个小关前、小关和小关之间、Boss 打完，都要有漫画转场；
  - 不许把几个场景（比如楼梯）不切换就硬接在一起。
- **怪物**：以「美少女 × 异变」或「校园物件 × 异变」为主，保持萌和"娘"。不要纯怪物，不要机器人。
  - 参考图 `art/ref/monster_ref.webp`，主要看里面"女体化 × 怪"的感觉。镜子（相框）怪、喇叭怪的思路是对的：看上去怪，但娘化了。
  - **不是给物件加一张女性的口、眼、鼻就叫娘化。**
  - 异化的是周围的同学、老师，以及校园物件。
- 「文化祭鬼屋失控」方向已被用户否决（跑题）。`docs/episodes/ep0_school.md` 是作废版本，只留作记录。

## 战斗节奏：射击和掩体（用户 2026-10-17）
- 玩家要熟悉"适当射击、酌情躲掩体"的切换节奏。
- **掩体不是完全无敌。**
- **有的敌方攻击需要提前打断**（靠硬直，见"战斗底子"）；**有的攻击必须躲掩体才行。**
- **Boss**：
  - 会变身；
  - 不同阶段用不同的战斗方式；
  - 弱点不一定一直可见。
  - 和上面"一条血、部位倍率不同"不冲突：弱点就是高倍率部位，只是有时藏起来。

## 美术：场景的技术路线（定稿，2026-10-17 用户纠正后，推翻前先问用户）
- **场景是真 3D，外观要像 2D 动画背景。** 镜头要能在里面推进、走位、演出。
- **关卡结构由 Claude 按玩法设计**，写在数据里：房间、桌椅柜子门窗、每个战斗点的掩体位置、怪物路线、镜头推进路线。
  - 掩体是关卡里摆的物体，不是从 GPT 画里抠出来贴上去。
- **画按几何来**：
  1. 从各镜头位置渲出白模图；
  2. 让 GPT 照白模"上色"成动画背景，构图不许改；
  3. 把画投影回白模（投影贴图）；画不到的面用同风格手绘材质补。
- 统一成 2D 观感：描边、卡通光影、纸质 / 网点后期。异变时地形真的折叠（参考 `art/ref/fold_city.png`、`fold_cubes.png`）。
- **作废的两条路**：
  - 旧的"3D 网格 + 平铺贴图"（不好看）；
  - 2026-10-17 做的"一张 GPT 静态画 + 深度模型鼓成假 3D"（镜头推不动、掩体硬贴，用户否决）。
  - GPT 单独画的场景 CG 不考虑几何合理性，只能当风格参考。
