# 设计（用户定下的，推翻前先问用户）

## 作品
- 名字暂定《相对希望少女们的扣击诗》。Three.js + Electron，面向 Steam/PC。
- 题材：每一集是一个恐怖题材的"异变"打断了 JK 的日常，两位灵能少女很生气，打穿异变、回到日常。无限单元剧，没有头尾。调性比《吊带袜天使》还瞎搞。
- **一个大关 = 完整致敬一部作品**（ACG / 恐怖小说 / 恐怖游戏），一集里不混别的作品。
  - 致敬前必须实际查资料，写进 `docs/episodes/<作品>.md`；
  - 桥段、氛围、名场面可以致敬，原作角色名、造型、怪物造型、台词不直接用。
- 章节：第 0 话是原创序章；其余章节都是致敬作，数量没定。第 1 话叫**腐蜜之家**（致敬《スウィートホーム》）。
- **对标成品**：不是占位的 MVP。除了还没做的音效音乐，画面、交互、转场都按上线标准。"看着不一样"是好事，重复感是缺陷。
- **美术不许偷懒复用**（用户说过多次，2026-10-17 再次强调）：墙、装饰、掩体、杂鱼、场景……同一种东西要有好几个"像又不完全一样"的版本轮着用，不让玩家看久了疲劳、细看觉得穿帮。Codex 出图没有额度限制（用户买了 Pro）。

## 主角
- 两人都是 **18 岁高三生**，成年人比例；允许 NIKKE 程度的晃动和身段表现（非露骨）。不擅自加安全裤之类的保守改动。设计图由用户定稿：`art/ref/cat_sheet.png`、`art/ref/pink_sheet.png`。
- 名字是假名谐音梗，中日英各有梗，不许另起：

| | 日 | 英 | 中 |
|---|---|---|---|
| 白发猫耳娘（右臂是猫爪鬼手，灵能系，不用枪） | 猫尾 果舞瑠（=猫を被る，装乖） | Neko O'Kaburu | 庄乖（=装乖） |
| 粉衣黑双马尾地雷妹（枪手） | 蘭堂 美音 | Rando Mine（=landmine；mine=我的） | 蔡蕾（=踩雷） |

- 猫爪手背上的咒印必须和设计稿右侧特写一模一样（细则见 ART）。
- 另一条路用户允许过但没批：咒印随场景 / 战斗状态变化，前提是应景、有设定（东方咒符 × 西方魔法阵）。

## 场景结构
1. 标题 + 设置：一个画面。
2. 选关 + 背包 + 换装：一个画面，像翻彩色漫画。
3. 大关：可配置的一串步骤，例如开场漫画 → 小关 → 漫画 → 小关 → 漫画 → Boss → 结尾漫画。
   - 小关之间、进第一个小关前、Boss 打完，都是漫画转场；
   - 不许把几个场景（比如楼梯）不切换就硬接。
4. 结算 → 回选关。结算像动漫分镜 / 名场面，贴合大关主题。
- 换画面像翻漫画：分镜重新排列（标题↔选关已做）。
- 漫画**不要文字**（序章已定；其他章节没说，默认也不要）。

## 操作
- 鼠标（1P）：移动瞄准；按住左键 = 探身射击；松开 = 躲掩体；右键 = 主动技能。没有别的按钮。
- 手柄：摇杆瞄准，RT/A 射击，LT/LB 掩体，Y/RB 主动，START 加入 2P / 菜单。2P 默认 AI，可随时被手柄或键盘接管。

## 战斗
- 从头到尾只有瞄准、射击。小关只在镜头和目标上变化，不换玩法类型。不做相生相克、不做要求瞬间换武器的设计。
- 小关里打完一波就往前推进到下一个位置再打，中间可以有演出镜头。
- **射击和掩体的节奏**：玩家要学会适当射击、酌情躲掩体。
  - 掩体不是完全无敌；
  - 有的攻击要提前打断（靠硬直）；
  - 有的攻击必须躲掩体。
- **硬直**：持续命中同一目标会累积硬直，打断它的攻击；杂鱼和 Boss 在某些动作中霸体。
- **暴击**只来自 Fever 的准头加成。基础手感开局就要舒服（射速不能低），Fever 只是加成。
- **Boss**：
  - 一条血，部位伤害倍率不同，不存在"必须先打爆某部位"；
  - 会变身，不同阶段打法不同，弱点（高倍率部位）不一定一直露出来；
  - 要**大**：屏幕里只看到局部，不是把图放大。
- **掩体**（2026-10-17 用户分三次定，以这里为准）：
  - 掩体是场景里本来就有的东西（由 Claude 按玩法摆）：角色到了一个地方，找到掩体，在掩体后面和敌人交战。不是跟着角色冒出来的；
  - 战斗时 1P、2P 都必须有自己的掩体，替她挡住怪物（在她和怪物之间）；
  - 大小适中：躲着时能护住她；探身射击时她明显露在掩体上面在打敌人，不能被整个挡住；也不能小到看不见。按游戏好看、好读来定，不追求现实比例；
  - **掩体和场景永远不挡主角立绘**（像 NIKKE：镜头在她身后，掩体在她再往前一点，她整个画在掩体上面）。用户原话："掩体和场景不要挡人物立绘……胜利女神 like，你天天挡人物，玩家看什么？"；
  - 也不能像她站在掩体里或穿过掩体（"角色现在就是穿模过掩体了"）：掩体底边在她脚的后面一点，从她身体两侧和下面露出来；
  - 掩体美术专门出，不拿别的素材凑（用户："掩体没有资产让 codex 出合适，你不要总是复用"）；
  - 打完一场往前走时，用过的掩体要退场（隐藏或退场动画），角色不能穿过掩体往前冲。
- **阵亡**：倒地后 9 秒倒计时；期间队友没倒下，倒计时结束就以半血复活（2026-10-17 用户）。
- **Fever**（鼓励一直打，不鼓励躲太久）：

| 指标 | 怎么涨 | 加成 |
|---|---|---|
| 伤害 | 造成伤害 | 伤害 |
| 准头 | 命中（打空只略降） | 暴击率、暴击倍率 |
| 连击 | 连续击杀不断 | 装填速度 |

  - 每项有等级；躲太久、长时间不开枪会衰减；被打中掉一截。
- **战斗中的表现不能打断节奏**（2026-10-17 用户）：
  - Fever 升级、必杀发动：不用横幅、不用全屏盖住的 cut-in；
  - 改为在对应角色立绘上做 shader 效果，加全屏边缘遮罩 shader。

## 角色性能（每人 = 枪械性能 + 一个贴人设的主动，不做被动）
- **物理净化流（枪，地雷妹）**：
  - 射速快、弹匣大、单发低、有穿透，适合打一群；持续打同一目标不断叠硬直。
  - 主动：无限弹匣加特林，伤害射速都上来，更易硬直，命中缓慢回血。充能靠命中。
- **灵能攻击流（鬼手，猫娘，致敬地狱老师）**：
  - 六字真言当子弹：单发高、杂鱼几发死，持续打同一目标伤害递增，射速一般，硬直长。
  - 主动：冲击波 / 真言镭射（贯穿），准星变慢，高伤；松开左键躲掩体会中断，并按剩余时间回血。充能靠时间 + 击杀，慢。

## 局外（不做抽卡、CG 奖励、素材链、消耗品）
- 唯一货币**刀盾**，按评价发放：解锁背包道具（永久、无限次）、扩充背包格子。
- 背包：道具有 cost，容量决定能带哪些，出发前搭配。
- 新大关、新角色：通关解锁。熟练度：用谁打谁涨，每级加一点枪械数值，满级解锁满破形态。
- 换装 / 满破：每套是一整套独立姿势素材，不做局部贴图替换。满破以后再做。

## 画面
- 主视觉：NIKKE 式主角背影 / 侧身在前景，战斗中看到全身（含脚），约半屏高。不靠缩放人物凑。
  - **赶路时只看膝盖以上**（2026-10-17 用户：没有合格的走路图，看全身很怪）：镜头推近、人物下移，进出战斗时有切换动画。
- **主角动起来靠晃动技术，不靠堆关键帧**（2026-10-17 用户）：
  - 用技术验证过的做法（单张 NIKKE 式静态立绘 + 程序化晃动、呼吸、射击弹动、汗，`晃动技术验证.bat`）；
  - 不是"所有姿势帧都齐了全用上就合格"，不乱用美术资产。
  - 立绘按状态用对（2026-10-17 用户）：蹲是蹲、射是射、装填是装填；走路时不能是蹲姿（2P AI 赶路时蹲着走被指出）。
- **射击特效**（2026-10-17 用户）：枪口、鬼手的 GPT 静态特效图之上叠 shader、粒子、光晕、动感等程序表现；普通射击和 Fever 时不一样。
- **特效要看得见**（2026-10-17 用户："人的眼睛不是像素级微妙检测设备"）：停留时间够长、效果够明显；要有美术素材打底，不是程序画几十毫秒就算。
- **晃动的手感**（用户反馈定的）：
  - 软肉从上沿挂着、下缘最软：猫娘是裙下尾巴根的臀部、腰侧；地雷妹是臀下缘、臀腿交界、侧乳。
  - 像果冻，有弹性和韧性，不是快速来回摇，核心约 2 Hz；强度默认 0.35（0.3～0.4）。
  - 站立射击：持续的低频节奏弹动（约 1.6 Hz）；每发一个快速"枪震"，地雷妹 13 发/秒也每发可见；射击时跟着枪晃。
  - 呼吸：站、蹲都一直有周期，越累越快越深；白气从**鼻尖**朝脸的方向呼出。
  - 尾巴不能带动小腿。
  - 汗：在皮肤上冒出、挂住长大、沿皮肤流下（出边就沿轮廓拐）、流干或碰到衣服就消失，留一道会干的水痕。**不往外飞溅**。
  - 环境氛围（光束、雾、灰尘）不要。
- **场景**：真 3D，看起来像 2D 动画背景。镜头能在里面推进、演出。技术路线见 ART「场景」，已由走廊验证确认（2026-10-17 用户："凑合了"）。
- **盗梦空间式的场景变化**：地板、墙、走廊能折起来、弯起来。
- **怪物**：怪物为主体再娘化。先一眼看出是异常的怪东西，再带少女特征，不是美少女挂物件，也不是物件上贴一张女人的脸。参考 `art/ref/monster_ref.webp`（相框怪、喇叭怪的思路对）。

## UI
- 风格：红黑白（P5 式），参考图 `art/ref/ui_p5.png`。用户原话："不然不是四平八稳的东西你就是对不齐"。
- 动漫式浮夸、可爱、有演出；不要扁平网页感、"高级感"，不要满屏小字配 SVG。浮夸不等于放大。
- **每个画面都要设计**：先出效果图给用户确认，再照效果图拆。战斗 HUD 也一样，不许不设计直接写样式（2026-10-17 用户："压根就是没设计"）。
- 从打开 exe 开始逐屏做：启动 → 标题+设置 ✔ → 选关 ✔ → 背包 / 换装 → 战斗 HUD → 结算。
- **战斗 HUD**（2026-10-17 用户选了版本 1「预告信」，`art/raw/r29/hud1_a.png`，并要求）：
  - 不挡人物演出（两位主角身上不压 HUD）；
  - HUD 自己要有 shader 动效：线条变化、图形层的动感，不是静止贴图；
  - 连击数和关卡名放最上方正中；Boss 血条（有 Boss 时）放最下方；
  - **准星随她的状态变**：躲着、瞄准空处、锁定怪物（拉线标出怪物名）、开火、装填、没子弹、Fever、必杀……每种在形状和组合上不同，不只是换色；准星本身会转、会组合、会变形（动画 + shader）。思路不确定就让 Codex 出几种方案的素材来比；
  - 残弹要好好设计：地雷妹几十发怎么显示；两人各自无限弹药（必杀中）时 HUD 怎么变；
  - Fever 三项（伤害 / 准头 / 连击）的计量表用颜色和图标区分开；
  - 残弹：地雷妹用弹匣刻度，猫娘用**符咒**（2026-10-17 用户）；
  - 没子弹、强制装填、装填中：那位玩家那一侧有半透明、若隐若现的提示，用 GPT 单独出的装填素材做成半透明，一看就知道在装弹（抽象的斜纹看不出来）；
  - 头像用 **Q 版表情包**（和正常比例的立绘不冲突，2026-10-17 用户），表情跟着状态来回换：受伤、连击升级、Fever、必杀好了、赶路、装填、射击、阵亡……每种有好几个可能。萌游戏，卖萌优先，不讲现实合理性。

## 序章（第 0 话，教学关）
- 剧情：放学前，两个互不认识的女孩各自看手机 / 笔记，想起今天要抢限定的周边 / 美食（不同的店；周边是别人家 IP 的），急着放学 → 学校被不明能量轰中 → 同学老师异化 → 一个掏枪、一个变出鬼手，共患难才相识 → 一路净化到操场打 Boss。
- 路线：教室 → 走廊 → 操场 Boss。**和学园祭 / 文化祭无关**（鬼屋方向已否，`docs/episodes/ep0_school.md` 作废）。
- Boss：巨大化风纪委员（用户 2026-10-17 定）。
